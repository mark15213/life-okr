# 桌面 Task 浮标与番茄钟 PRD

版本：v1.0

日期：2026-09-13

项目：Life OKR / 人生看板

目标平台：Windows 桌面客户端、macOS Apple Silicon（ARM）桌面客户端

## 1. 产品定位

一个可以 pin 在桌面上的图标式浮标：突出显示全局番茄钟的剩余时间、已经执行的时间和当前 Task，通过快捷键切换任务，并在到时获得提醒。一轮番茄可以包含多个任务的专注片段，例如 30 分钟内 Project A、B、C 各投入 10 分钟。

核心模型：一轮全局番茄 → 多个按时间顺序记录的任务片段。切换任务只改变之后时间的归属，全局倒计时连续进行，不重置、不创建新番茄。切回某任务时接着累计该任务的投入时间，任务本身没有独立的番茄倒计时。

主界面负责管理，桌面浮标负责日常操作。用户无需持续打开浏览器或反复返回主窗口。

## 2. 已确认需求与草案假设

### 用户明确提出

- 提供本地桌面客户端，覆盖 Windows 和 ARM Mac。
- 有一个图标式桌面浮标，可 pin 在桌面上，直接看见计时信息。
- 浮标突出显示一个总的番茄剩余时间，到时提醒；按最新简洁性要求，本轮已执行和分任务用时移至展开面板。
- 使用快捷键在不同 Task 之间快速 context switch；同一轮内可分配时间给多个任务。
- 清楚显示当前 Task、每个 Task 在本轮的投入，以及累计用时。
- 当前任务可以暂停，也可以切换到另一个任务。

### 本文建议默认值，尚非用户确认

| 决策 | 本版建议 | 原因 |
|---|---|---|
| 浮标形态 | 一个常驻浮标，展开后显示任务切换器 | 避免多个任务窗口占满桌面 |
| “固定在桌面” | 默认置顶于普通应用窗口，可拖动、记住位置、锁定位置 | 工作时也能看见倒计时；是否需要真正嵌入桌面层另行确认 |
| 暂停语义 | 暂停当前工作时，全局番茄和任务计时一起暂停；暂停中切换仅更改任务，继续后再计时 | 避免无人工作时仍消耗番茄时间；具体暂停规则为建议默认值 |
| 并行计时 | 同一客户端最多一个任务计时 | 避免把同一段工作时间重复归属 |
| 默认番茄时长 | 30 分钟，可选 15 / 25 / 30 / 45 / 60 分钟 | 延续项目现有默认值 |
| 任务来源 | 延续 TickTick 任务，缓存后可离线计时 | 对接现有工作流 |
| 统计范围 | 优先展示本轮任务用时，展开可看今日、累计及每轮番茄历史 | 本轮分配直接可见，不把未导入的历史冒充完整历史 |
| 跨设备 | 首版各设备独立计时，不承诺实时接力 | 先完成桌面核心闭环 |

## 3. 项目现状与变化

以下为代码现状，不代表桌面能力已经实现：

- `components/FloatingTasks.tsx` 已提供网页内任务面板、任务操作及番茄钟；开始另一个任务会结算当前番茄，再创建新番茄。
- `lib/ticktick/pomodoro.ts` 已有开始、暂停、恢复、剩余时间计算、浏览器持久化和待上传记录结构；当前不足 60 秒的会话不会上传。
- 当前项目是 Next.js Web 应用；本次需要补充桌面窗口、托盘/菜单栏、全局快捷键、系统通知和本地可靠存储能力。
- 桌面版需要把番茄改为全局会话，由多个任务专注片段关联到同一轮；番茄会话不再绑定唯一 Task。现有网页“切换即结束”的规则与本需求不同。

技术框架、安装签名及分发方案在技术设计阶段确定，本文不预选 Electron 或 Tauri，也不承诺未经验证的系统窗口行为。

## 4. 目标、范围与非目标

### 首版必须完成（P0）

1. Windows 与 Apple Silicon Mac 可安装并独立运行。
2. 可拖动、置顶、锁定位置的单一桌面浮标。
3. 全局番茄钟：开始、暂停、恢复、提前结束、到时提醒。
4. 鼠标与全局快捷键快速切换任务，同一轮倒计时持续，分任务累计用时。
5. 显示当前任务、当前轮已执行和剩余时间、各任务本轮/今日/累计用时，以及每轮历史记录。
6. 本地持久化、断网可用、系统休眠与异常退出后的明确恢复行为。
7. TickTick 任务读取与缓存；同步失败不阻塞本地计时。

### 后续增强（P1）

- 短休息/长休息及自动循环、轻量“下一步”备注。
- 新建任务、从浮标完成远端任务、专注记录回写 TickTick/同步人生看板。
- 开机启动、自定义主题、任务历史导入、记录导出与手动修正。
- 跨设备接力和与网页端的活动计时协调。

### 本版不做

- 自动切换或恢复 IDE、浏览器标签及文档；context switch 首版只切换任务和计时状态。
- 多任务同时计时、团队协作、完整项目管理、屏幕监控与自动判断工作内容。
- 为每个任务生成独立浮窗、手机端、Intel Mac 与 Windows ARM 的发布承诺。

## 5. 主要使用流程

### 开始工作

打开客户端 → 读取任务或本地缓存 → 选择 A → 开始番茄 → 收起主窗口 → 浮标显示 A、剩余时间与今日用时。

### 一轮内切换多个任务

开始一轮 30 分钟番茄，当前为 Project A → 做 10 分钟后切到 B，全局剩余 20 分钟 → B 做 10 分钟后切到 C，全局剩余 10 分钟 → C 做 10 分钟，到时结束。

结果：只完成一轮番茄，已执行 30 分钟；本轮分配为 A 10 分钟、B 10 分钟、C 10 分钟。任务切换不要求预先设定每个任务的时间配额。

往返示例：A 做 8 分钟，B 做 5 分钟，再回到 A，此时全局剩余 17 分钟，A 本轮累计 8 分钟并继续增加，B 停在 5 分钟。

### 暂停工作

一轮已执行 12 分钟、剩余 18 分钟 → 点击暂停或使用暂停快捷键 → 全局与当前任务均停止计时 → 暂停 5 分钟后继续 → 仍剩余 18 分钟。暂停中可选择 B，只有点击继续后才开始给 B 计时。

### 番茄结束

倒计时到 00:00 → 结算当前片段和整轮番茄 → 浮标进入“本轮完成”状态 → 发出一次提醒 → 展示本轮实际执行时间及 A/B/C 用时分布 → 用户选择任务并明确开始下一轮。番茄完成不自动标记任何任务完成，切换任务也不自动开始下一轮。

## 6. 功能与交互要求

### 6.1 桌面浮标

- 紧凑状态采用约 256 × 48 逻辑像素的单行深色胶囊，仅保留 `mm:ss` 全局剩余时间、分类小圆点、当前任务名和暂停/继续图标。不常驻标题、品牌、进度圆环、已执行时间或任务用时统计。
- 点击任务名展开切换器和详细用时；较长任务名截断，悬停或展开查看全文。空白处可拖动，置顶和位置锁定设置收纳于展开面板或右键菜单。
- 视觉统一现有前端：Hustle. 报刊式衬线品牌标题仅用于主界面；浮标使用 zinc-900 底色和白字，展开面板使用白底、浅灰边框、灰色选中态、无衬线文字与等宽数字。分类颜色沿用 Work 紫、Study 青、Hustle 琥珀、Life 玫红、Inbox 灰，不另设绿色主题。同分类任务共享分类色。
- 展开状态提供本轮各任务用时列表、任务切换器、今日及累计用时，以及番茄历史入口；不展示各任务独立倒计时。
- 无活动任务时显示“选择任务开始”；暂停时保留倒计时并明确标记“已暂停”。
- 支持拖动、屏幕边缘吸附和位置锁定；锁定仅禁止拖动，按钮仍可操作。
- 记住所在显示器与位置；显示器断开或缩放变化后，浮标回到可见区域。
- 用户可关闭置顶、隐藏浮标，并从托盘/菜单栏重新显示。隐藏不暂停计时。
- 浮标不主动抢占键盘焦点；只在用户打开切换器时接收输入。
- 首版保证普通应用窗口上的可见性；macOS 全屏/Spaces、Windows 虚拟桌面的跟随行为需原型验证后确定支持范围，不覆盖系统安全界面。

### 6.2 快速任务切换

- 点击浮标入口或使用可配置的全局快捷键打开切换器，不占用系统 Alt+Tab / Command+Tab。
- 拟定默认唤起键：Windows `Ctrl + Alt + K`，macOS `Control + Option + K`（`⌃⌥K`）；不是 Command 键。切换器内 `↑ / ↓` 选择、`Enter` 确认、`Esc` 关闭。默认组合需实机注册与冲突验证，支持改绑。
- 实现状态：独立桌面端已实现全局唤起和任务切换，Windows 原生测试已验证注册；原网页仍仅提供 `Esc` 关闭面板。Mac 默认键位已配置，待 Mac 实机验证。
- 列表优先显示当前任务和最近使用任务，支持按标题搜索、方向键选择、Enter 确认、Esc 取消。
- 打开、搜索、取消不改变计时归属；确认选择的瞬间才切换。
- 从正在计时的 A 切到 B：以同一时间点结束 A 的片段并打开 B 的片段，保持同一番茄标识和剩余时间，不等待网络、不产生计时空档或重叠。
- 切回 A 时给 A 打开新片段，合并展示 A 在本轮所有片段的用时；不恢复任何任务独立倒计时。
- 全局暂停中切换只更新当前选中的任务，保持暂停，明确“继续”后才开始计时。
- 重复选择当前任务不重置、不新增记录；全局暂停状态下可通过明确的“继续”动作恢复当前任务。
- 提供可配置的“切回上一任务”和“暂停/继续”全局快捷键，默认分别为 `Control+Alt+J` 与 `Control+Alt+P`（Mac 的 Alt 对应 Option）；前者可在最近两个任务间直接往返。无上一任务时不改变计时状态。
- 快捷键冲突时提示并允许改绑；键盘入口不可用时鼠标操作仍完整可用。

### 6.3 番茄钟与计时状态

| 状态/事件 | 规则 |
|---|---|
| 未开始 → 开始 | 选择任务后创建全局番茄，并打开首个任务片段 |
| 计时中 → 暂停 | 结算当前专注片段，冻结剩余时间 |
| 已暂停 → 继续 | 打开新专注片段，接续原番茄 |
| 运行中切换任务 | 全局倒计时连续进行，结束原任务片段并打开目标任务片段 |
| 暂停中切换任务 | 只更改选中任务，不恢复计时 |
| 到时完成 | 剩余归零，自动停止并提醒，不计超时用时 |
| 提前结束 | 保留实际专注时间，标记为提前结束，不算完整番茄 |
| 修改默认时长 | 只影响之后新建的番茄，当前全局番茄不变 |

同一客户端最多一轮未结束番茄，运行时必须且只能有一个当前任务。暂停时没有运行中的片段，但保留任务选择。任务今日及累计用时不随番茄结束清零；新一轮的本轮用时从零开始，旧轮保留在历史中。提前结束后再次开始会创建新一轮。

### 6.4 提醒

- 当前运行番茄到时：浮标显示持久的完成状态，并请求发送一条系统通知；可选提示音，默认开启。
- 通知包含“本轮已完成”、本轮执行时长及结束时的任务名称；点击后显示本轮总结，不暗示全部时间都用于最后一个任务。
- 同一轮只提醒一次，重复唤醒、同步重试或重启不得重复发声。
- 通知未授权时展示设置入口；系统勿扰或静音可能限制外部提醒，浮标的完成状态仍保留。
- 不弹出阻塞工作的大对话框，不自动启动下一轮。

### 6.5 每个任务的用时

- **当前轮已专注**：该番茄所有有效专注片段之和。
- **当前轮剩余**：设定时长减去当前轮已专注，最小为零。
- **任务本轮用时**：本轮中属于该任务的所有有效片段之和；A → B → A 的两段 A 合并展示，也可在详情查看切换顺序。
- **今日用时**：归属于该任务、落在统计日期内的有效专注时长，含提前结束及正在进行的片段。
- **累计用时**：自本客户端开始记录以来该任务的有效专注时长；详情显示记录起始日期。
- 切去其他任务后，原任务用时停止增加，全局与目标任务继续增加；全局暂停、休眠和应用完全退出期间两者均不增加。
- 本地保留秒级短片段，不能因快速切换而丢掉不足一分钟的工作时间；展示可按分钟格式化，汇总后再取整。
- 统计时区默认 Asia/Shanghai（延续项目），可在后续设置中调整；跨午夜片段按日切分。与现有按番茄起始日归属的同步统计口径存在差异，接入看板前需统一。
- 当前轮时长与累计投入分别标注，避免把“这轮做了多久”误当成“任务总共做了多久”。
- **守恒规则**：一轮内所有任务用时之和 = 本轮实际专注时间；完整结束时等于设定时长，提前结束时小于设定时长。暂停时间不参与分配。
- **每轮历史**：提供日期、开始/结束时间、设定时长、实际执行时长、完成/提前结束状态，以及各任务用时分布。墙上经过时间（含暂停）与实际执行时间分别标注；暂停的未结束轮显示在当前会话中。

### 6.6 本地运行与异常恢复

- 关闭主窗口：保留托盘/菜单栏进程，继续计时；完全退出：保存并暂停。首次关闭时用非阻塞提示说明。
- 锁屏和系统休眠：自动暂停，不把离开时间记作工作；解锁/唤醒后保持暂停，由用户继续。
- 异常崩溃：恢复到最近持久化点并暂停，显示恢复提示，不将退出至重启间隔补算为专注。
- 切换、暂停、结束等状态变化立即持久化；运行中周期性保存，异常退出的未保存用时目标不超过 5 秒。
- 系统时钟调整不使倒计时跳变或产生负时长；展示刷新与真实经过时间分离。
- 本机只允许一个计时实例；重复启动唤起已有实例。
- 断网后，缓存任务可启动、切换、计时并保存；首次使用无缓存时明确说明需联网读取任务。
- 当前任务在远端被删除或完成：保留历史及名称快照，发现变更后暂停全局番茄并提示，用户选择有效任务后主动继续。非当前任务的远端变化不影响计时。
- 两台设备或网页与客户端同时计时的记录首版不自动合并；统计明确标注来源，不声称账号级唯一计时。

## 7. 数据与集成边界

最低限度的数据概念：

| 对象 | 必需信息 |
|---|---|
| Task | 稳定标识、来源及外部标识、名称、状态、本地缓存时间 |
| Pomodoro | 唯一标识、设定时长、状态、开始/结束时间、累计有效时长、当前选中 Task 标识、结束原因；一轮可涉及多个 Task |
| FocusSegment | 唯一标识、Task/番茄标识、任务名称快照、起止时间、有效时长、设备来源 |
| DesktopPreferences | 浮标位置、置顶/锁定状态、默认时长、快捷键、提醒偏好 |

本地专注片段是桌面统计的依据，上传成功与否不改变本地用时。凭据不得写入普通日志或随桌面安装包分发；桌面登录及凭据存储方式由技术设计明确。

首版读取 TickTick 任务，但不把专注回写作为本地核心流程的前置条件。后续接入现有 focus API 时，必须解决一轮多任务到现有单任务上传结构的映射、不足 60 秒片段、同任务多片段、重试去重，以及同步回流后的重复统计问题；不得直接把“本地总数 + TickTick 总数”相加。即使外部系统需要拆分上传，本地仍只统计一轮番茄，不能把 A/B/C 三个片段计成三轮。

## 8. 验收标准

以下是目标，需在 Windows 与 Apple Silicon Mac 实机分别验收。

| 编号 | 场景 | 通过条件 |
|---|---|---|
| A01 | 安装并启动 | 两个平台均能独立启动；关闭主窗口后仍可通过托盘/菜单栏操作 |
| A02 | 持续可见 | 普通应用切到前台时，开启置顶的浮标仍可见，并显示任务和剩余时间 |
| A03 | 实时计时 | 正常运行时每秒刷新；连续运行 60 分钟，计时误差不超过 1 秒 |
| A04 | A/B 往返 | 30 分钟一轮中 A 做 8 分钟、B 做 5 分钟后回 A，全局剩余 17 分钟；两任务本轮分别累计 8、5 分钟，番茄标识不变 |
| A05 | 快速切换 | 已缓存任务切换确认后 300ms 内更新当前任务；无重复运行和重复记录 |
| A06 | 取消选择 | 切换器搜索后 Esc，原任务计时持续且归属不变 |
| A07 | 短片段 | A/B 各切换专注 20 秒，两个任务各保留 20 秒，不被分钟阈值丢弃 |
| A08 | 到时提醒 | 运行且通知获准、勿扰关闭时，到时 2 秒内发起通知；浮标归零并停止；同轮不重复提醒 |
| A09 | 暂停与退出 | 暂停、锁屏、休眠和完全退出期间不增加专注时间；恢复后需主动继续 |
| A10 | 崩溃恢复 | 可恢复当前任务、同一全局番茄剩余时间及各任务片段，无退出期间虚增用时；未保存用时不超过 5 秒 |
| A11 | 离线 | 已缓存 A/B 在断网期间仍可切换并保存，重启后记录存在 |
| A12 | 多屏 | 重启记住位置；拔掉浮标所在显示器后浮标仍能在剩余屏幕找到 |
| A13 | 跨日 | 23:55 至次日 00:05 的有效专注，两天各归属 5 分钟 |
| A14 | 权限与快捷键 | 禁用通知/快捷键冲突时有明确状态，浮标操作和本地计时不受影响 |
| A15 | 30 分钟三任务 | A/B/C 各执行 10 分钟，全局归零，只完成并提醒一轮；本轮任务用时之和为 30 分钟 |
| A16 | 暂停中切换 | 剩余 18 分钟时暂停并切到 B，等待 5 分钟后仍剩余 18 分钟，B 不增加用时；继续后才给 B 计时 |
| A17 | 每轮历史 | 结束一轮后重启客户端，仍可查看该轮实际执行时间和 A/B/C 分布；新一轮本轮统计归零，历史与累计不丢失 |
| A18 | 直接切回 | 运行中使用“切回上一任务”快捷键，A/B 往返不重置全局倒计时，片段归属准确 |

产品体验目标：仅看极简浮标即可识别“全局剩余、当前任务、运行/暂停状态”；展开后查看本轮已执行与任务投入。鼠标在浮标展开后一次选择即可切换；键盘用户全程无需鼠标。

## 9. 首版决策与后续验收

首版采用以下决策：

1. 单一深色胶囊浮标，置顶于普通应用窗口，可拖动及锁定位置。
2. 全局番茄内切换任务保持倒计时连续；暂停同时停止番茄和任务计时，暂停中切换仍保持暂停。
3. 支持创建本地任务，以及从已连接的人生看板读取 TickTick 任务。
4. 今日及累计用时以本机记录为准，TickTick 历史导入与专注回写延后。
5. 休息倒计时、多个独立浮窗和跨设备接力延后。
6. 发布目标为 Windows x64 与 macOS ARM64；Mac 实机、全屏/Spaces、多屏/DPI、真实休眠、通知勿扰及长时间误差需完成平台验收。
